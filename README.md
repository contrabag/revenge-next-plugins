# Revenge Next Plugin(s?) - contrabags 

A singular plugin for Revenge Next.

## Plugin

### System Emoji

Replaces Twemoji with system emoji in messages, ported to Next.

* Same behavior as Nexpid's original plugin, down to the flaws

### Install

Add the following repository to Revenge Next:

```text
https://contrabag.github.io/revenge-next-plugins/
```

Then install **System Emoji** from the plugin list.
