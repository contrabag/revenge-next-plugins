# Revenge Next Plugins - contrabags 

Ported plugins for Revenge Next.

## Plugins

### System Emoji

Replaces Twemoji with system emoji in messages, ported to Next.

* Same behavior as Nexpid's original plugin, down to the flaws. (+ small improvements)

### File Size on Picker

Show the file sizes in the media picker, ported to Next.

* Same behavior as MSMA's legacy vendetta plugin.

### RealMoji

Makes freemojis real (Client-side only), ported to Next

* Same behavior as redstonekasi & Purple Eye's original plugin, down to the flaws.

## Install

Add the following repository to Revenge Next:

```text
https://contrabag.github.io/revenge-next-plugins/
```

Then install whichever plugin by contrabags from the plugin list.
